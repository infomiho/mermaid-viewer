# Context

## Terms

### Mermaid viewer

A static browser tool for editing Mermaid source and inspecting the rendered diagram.

### Preview viewport

The interactive area that displays the rendered Mermaid diagram and owns fit, zoom, pan, and reset behaviour.

### Preview rendering

The Mermaid viewer behaviour that turns Mermaid source into preview output, including render errors and rendered SVG state.

### Shareable source URL

The URL hash that stores compressed Mermaid source so a diagram can be shared by copying the browser URL.
