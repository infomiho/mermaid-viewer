# AGENTS.md

This is a minimal static Vite app for previewing Mermaid diagrams.

- Keep the UI tool-like: compact, black and white, technical, with Majorel blue accents only where useful.
- Keep dependencies minimal.
- Use `npm run build` to verify changes.
- Deploy with `npm run deploy`, which publishes `dist/` to the `mermaid` Buzz subdomain.
